# 绕圈圈 Orbit Flip

一根手指就能玩的手机小游戏：点击屏幕在内外圈之间切换，躲开障碍、吃掉 ◆，越转越快。最后一刻闪开可以触发「惊险」连击加分。

纯 HTML + Canvas，单文件，无依赖。用 GitHub Pages 托管即可在 iPhone Safari 上直接玩，也可以「添加到主屏幕」。

在线游玩：https://wilsonmah.github.io/orbit-flip/
